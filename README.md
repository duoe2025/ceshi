## HTML5 网页版（Phaser 3）

本仓库正按《[开发计划](./docs/开发计划.md)》第三部分推进「大卫一生」HTML5 ARPG：
**逻辑核心保持引擎无关（已 39/39 无头单测），表现层迁移到 Phaser 3**。

- 一键构建：`cd tools && npm install && npm run build:phaser` → 产出 `html5/game.js`
- 本地试玩：用浏览器打开 `html5/index.html`（或 `python3 -m http.server` 后访问）
- 入口与场景：`assets/scripts/phaser/`（`main.ts` 创建 `Phaser.Game`，`GameScene` 承载第一章）
- 模块化引擎入口：`assets/scripts/engine/`（StatsEngine/LootEngine/MapEngine… 见开发计划 §12）

> Phaser 场景复用同一套引擎无关逻辑核心；第一章作为模板，后续每一幕/每张地图按此扩展。

## 工程架构：引擎无关核心 + 薄渲染层

为了方便复用与测试，逻辑与渲染完全分离：

```
assets/scripts/
├── core/                 # 纯 TypeScript 逻辑，不依赖 Cocos / DOM（可 node 直接验证）
│   ├── types.ts          #   类型定义
│   ├── GameData.ts       #   静态数据：地图、瓦片、敌人、武器、NPC、对白
│   └── GameCore.ts       #   即时战斗 / 移动碰撞 / 敌人 AI / 任务流程 / 对白状态机
├── Painter.ts            # 把「屏幕坐标」2D 绘制适配到 Cocos Graphics
├── Sprites.ts            # 程序化像素绘制（瓦片 / 角色 / 敌人，无图片资源）
└── GameController.ts     # Cocos 组件：渲染 + 键盘/触摸输入 + 接入 core
```

- **微信小游戏没有 DOM**，所以所有 UI（对白框、HUD、血条、任务日志、结算）都
  **画在画布上**，不使用任何网页元素。
- 渲染全部为**程序化绘制**，不依赖图片资源，开箱即跑。
- 核心逻辑可在 Node 下无头验证（见下文），无需打开编辑器即可回归测试关卡流程。

# 牧童大卫 · 第一章 Demo

一个**纯网页**（HTML + Canvas + 原生 JavaScript，零依赖）的像素 RPG 试玩 Demo，验证「牧童大卫」第一章的核心玩法：**探索牧场 → 找回走失的羊 → 回合制战斗击退猛狮 → 夜里弹琴驱散邪灵**。三种武器各有用途：**弹弓**（远程攻击主力）、**杖与杆**（近战护羊）、**弹琴赞美**（驱邪安抚）。

## 玩法

- **移动**：方向键 或 `WASD`
- **互动 / 确认**：`空格` 或 `回车`
- **任务日志**：`Q` 开关
- **战斗**：方向键选择技能，`空格` / `回车` 确认（也可鼠标点击）

## 第一章流程

1. 开场后走到**父亲耶西**身边交谈，接到任务。
2. **找回走失的 3 只羊**：在牧场各处走近迷路的羊即可带回。
3. 回去向父亲复命，触发剧情：**猛狮来袭**。
4. 前往东边**山洞**，进入**回合制战斗**，用弹弓/杖杆击退猛狮（物理攻击对野兽有效）。
5. 当夜羊圈门口出现**邪灵**：物理攻击几乎无效，必须用**弹琴赞美**将其驱散，完成第一章。

战斗技能：投石索（弹弓·远程主力）、杖与杆（近战·护羊）、弹琴赞美（驱邪·安抚）、守势（减伤+回血）、祷告（回血）。

> 设计说明：敌人分 `beast`（受物理伤害）与 `spirit`（几乎免疫物理、惧怕弹琴）两类，以此强制三种武器各有用武之地。

## 运行

无需安装与构建，直接用浏览器打开 `index.html` 即可游玩。

如需本地用服务器方式运行：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

```

css/style.css     样式
js/data.js        地图、瓦片、实体、任务、对白等静态数据

js/ui.js          对白、HUD、提示、任务日志
js/battle.js      回合制战斗
js/game.js        主引擎：渲染、移动、互动、任务流程、输入
```
