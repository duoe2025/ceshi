# 牧童大卫 · 开发计划文档

> 本文件是游戏《牧童大卫》的开发计划（设计文档）。
> 第一章可玩 Demo 已实现（见仓库根目录 `index.html` 与 `js/`）。
> 本文档在 Demo 基础上规划后续核心系统，重点是 **35 位勇士（同伴）系统** 与 **先知（医治 / 驱魔）系统**。
>
> 注：旁注里的圣经出处仅作设定依据，方便对齐人物与事件，可按实际企划调整命名与数值。

---

## 0. 总览

大卫的一生贯穿三条主线，三种核心武器（已在 Demo 验证）也贯穿始终：

| 武器 | 用途 | 对象 | 设计含义 |
|---|---|---|---|
| 弹弓（投石索） | 远程攻击主力 | 物理敌人（野兽、巨人、敌兵） | 大卫的招牌，打歌利亚的关键 |
| 杖与杆 | 近战 · 护羊 | 物理敌人、贴身缠斗 | 牧人本职，保护羊群 |
| 弹琴赞美 | 驱邪 · 安抚 | 邪灵免疫物理，唯弹琴可驱散；对野兽起安抚 | 赞美神，驱赶恶魔（撒上 16:23） |

在此之上，本计划新增两大长期养成系统：

1. **勇士系统**：大卫一生中陆续招募的勇士（gibborim），通过各种剧情事件获得，组队并肩争战。**名册严格按圣经对齐**：以「撒母耳记下 23:8-39」为主（三勇士 + 三十勇士，“共三十七人”），并补以「历代志上 11:10-47」的平行名册及额外勇士。
2. **先知系统**：撒母耳、拿单、迦得等先知，提供 **膏立、预警、医治、驱魔** 等非战斗与辅助战斗能力。

## 1. 勇士系统（大卫的勇士 / gibborim）

### 1.1 设计定位

- 勇士是大卫的 **可招募同伴**，不是一次性 NPC。
- 每位勇士通过 **特定剧情事件 / 支线** 解锁（不是商店购买），强调「患难中结义」。
- 战斗中可带 **1 名队长 + 至多 3 名出战勇士**（共 4 人小队，含大卫则 5 人），其余在「勇士营」待命。
- 每位勇士有 **1 个招牌技能**（取材于其圣经事迹），以及成长属性。
- **人物忠于圣经**：撒下 23 明说「共三十七人」（三勇士 + 以亚比筛/比拿雅为首的三十勇士）；代上 11 的名册更长，末尾（11:41-47）另有若干不见于撒下的勇士。本作将**两处名册合并收录**，不需凑数；可招募勇士约 **50 位**（含历代志补录），具体上阵与图鉴收录可由策划划定。
- 约押（元帅）、亚比筛、比拿雅因地位特殊，另设为「核心三将」单独成线（见 1.5）。

### 1.2 招募方式（事件驱动）

招募统一走「事件 → 条件 → 入队」流程，便于扩展：

```
事件触发（到达地点 / 完成任务 / 战斗胜利 / 对白选择）
   → 满足条件（等级 / 持有物 / 前置勇士 / 章节进度）
   → 播放招募过场（该勇士的来历与誓言）
   → 加入「勇士营」，可编入小队
```

典型招募事件类型：
- **解围救援**：在某战斗事件中救下被围的勇士（如亚多兰陷阵），战后入队。
- **比武 / 立功**：完成勇士给出的考验（如比拿雅雪天坑中打狮子的回忆任务）。
- **共御外敌**：非利士人来袭，几位勇士一同死守麦田（沙玛守麦田，撒下 23:11-12），守住后入队。
- **忠义感召**：大卫逃亡基云时，亡命之徒陆续来投（撒上 22:1-2），形成早期勇士池。
- **取水明志**：三勇士闯非利士营为大卫取伯利恒井水（撒下 23:15-17），触发「三勇士」结义。

### 1.3 战斗中的勇士（并肩争战）

- 小队制：回合制战斗里，大卫与出战勇士 **各自行动一次**（按敏捷/速度排序出手）。
- 每位勇士有 **职业定位**：陷阵（前排高攻）、护卫（前排高防/护羊护人）、弓手（远程）、勇将（爆发斩杀）、副手（armor-bearer，可替队友挡伤/递弹药）。
- **羁绊**：特定勇士同时出战触发增益（如「三勇士同列」→ 全队暴击率提升）。
- **协战技**：大卫弹琴赞美时，在场勇士获得「士气」增益（呼应「赞美鼓舞军心」）。

### 1.5 核心三将（独立剧情线）

- **约押**：元帅型，统军；剧情中亦有争议（杀押尼珥、亚玛撒），可做「忠而难驭」的复杂角色。
- **亚比筛**：三十勇士之首，「举枪敌三百」（撒下 23:18），救大卫脱离非利士巨人（撒下 21:17）。
- **比拿雅**：勇力传奇——**雪天下到坑中打死狮子**、击杀两个摩押勇士、夺埃及巨人的枪反杀（撒下 23:20-21）；后为大卫侍卫长。其「坑中屠狮」可做成一段可玩回忆战，与第一章大卫打狮呼应。

## 2. 先知系统（医治 / 驱魔）

### 2.1 设计定位

先知不是普通战士，而是 **属灵支援单位**，承接 Demo 已确立的「属灵 vs 物理」主题（弹琴驱邪灵）。先知能力分两类：

- **非战斗（剧情/世界）**：膏立、预言指引、定罪与悔改、解锁路线。
- **战斗辅助（出战或后援）**：医治、解除诅咒、驱魔（对邪灵/受邪灵附身者特别有效）。

### 2.2 主要先知

| 先知 | 阶段 | 能力（设计） | 依据 |
|---|---|---|---|
| 撒母耳 | 早期 | 「膏立」：永久提升大卫成长；圣所庇护回血 | 膏大卫（撒上 16:13） |
| 拿单 | 王朝期 | 「指正」：解除「罪/心魔」debuff；预言指引支线 | 责大卫（撒下 12） |
| 迦得 | 逃亡—王朝 | 「先见预警」：战前预知敌方弱点/布阵 | 大卫的先见（撒下 24:11） |
| 亚比亚他（祭司） | 逃亡期 | 「以弗得求问」：战前占卜，提示最优技能 | 携以弗得来投（撒上 23:6-9） |

> 后世先知以利亚 / 以利沙（医治、复活、驱逐邪灵之事）不属大卫时代，仅作能力设计灵感来源，不入大卫主线名册。

### 2.3 医治与驱魔机制

- **医治（Heal / Cure）**
  - 单体/群体回复体力；进阶可「复元」解除中毒、流血、虚弱等状态。
  - 与大卫已有「祷告（回血）」区别：先知医治更强、可群疗、可解状态，但先知为稀有支援位，CD/次数受限。
- **驱魔（Exorcism / Dispel）**
  - 对 **邪灵 / 被附身者** 命中率与伤害大幅提升（与弹琴赞美形成「双驱邪手段」：弹琴是大卫自带，先知驱魔是支援强化）。
  - 可 **解除附身**：部分敌人是「被邪灵附身的人/兽」，驱魔后变为可对话/可救助对象（呼应「救人非灭人」）。
  - 对邪灵 BOSS：先知驱魔 + 大卫弹琴的 **合击** 触发额外效果（如「赞美与代祷」combo）。

### 2.4 与勇士系统的协同

- 先知 **不占出战格**，作为「后援位」每战提供 1 次支援（医治或驱魔），鼓励「勇士冲锋 + 先知托底」的配置。
- 邪灵类战斗中，纯物理勇士输出被压制（延续 Demo 机制），必须依赖大卫弹琴或先知驱魔，强化主题表达。
