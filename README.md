# 牧童大卫 · 第一章 Demo

一个**纯网页**（HTML + Canvas + 原生 JavaScript，零依赖）的像素 RPG 试玩 Demo，验证「牧童大卫」第一章的核心玩法：**探索牧场 → 找回走失的羊 → 回合制战斗击退猛狮**。

## 玩法

- **移动**：方向键 或 `WASD`
- **互动 / 确认**：`空格` 或 `回车`
- **任务日志**：`Q` 开关
- **战斗**：方向键选择技能，`空格` / `回车` 确认（也可鼠标点击）

## 第一章流程

1. 开场后走到**父亲耶西**身边交谈，接到任务。
2. **找回走失的 3 只羊**：在牧场各处走近迷路的羊即可带回。
3. 回去向父亲复命，触发剧情：**猛狮来袭**。
4. 前往东边**山洞**，进入**回合制战斗**，用投石索/牧杖击退猛狮，完成第一章。

战斗技能：投石索（远程·准）、牧杖击（近战·稳）、守势（减伤+回血）、祷告（回血）。

## 运行

无需安装与构建，直接用浏览器打开 `index.html` 即可游玩。

如需本地用服务器方式运行：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 目录结构

```
index.html        页面骨架与各 UI 层
css/style.css     样式
js/data.js        地图、瓦片、实体、任务、对白等静态数据
js/sprites.js     程序化像素绘制（瓦片与角色，无图片资源）
js/ui.js          对白、HUD、提示、任务日志
js/battle.js      回合制战斗
js/game.js        主引擎：渲染、移动、互动、任务流程、输入
```
