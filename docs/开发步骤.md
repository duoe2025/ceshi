## M2 · 完全 Phaser 原生化 · 阶段2（✅ 完成：粒子 + 相机特效）

**目标**：把自绘 VFX 与受击反馈替换/增强为 Phaser 原生粒子 / 相机能力。
> 采用「原生粒子叠加在自绘 VFX 之上」的增强方案：自绘图元保证与 Canvas 版观感一致、零回归；原生粒子提供 WebGL 批量打击感。`sparks`(命中) / `motes`(升级·暴击 金色) / `beams`(掉落光柱) 三个原生发射器。

- [x] 命中迸溅 → `ParticleEmitter`（`sparks.explode`，按命中点世界坐标）
- [x] 升级光环 → 金色粒子爆发（`motes.explode` + `camera.flash` 金闪）；暴击也喷金色光点
- [x] 掉落光柱 → 粒子上升光束（`beams`，`particleTint` 按物品稀有度着色）
- [x] 受击红闪 → `camera.flash`（受击帧触发）
- [x] 重击 / 震屏 → `camera.shake`（core.shake 触发）
- [x] 夜战压暗 → 原生 `Phaser.GameObjects.Rectangle` 固定层（`setScrollFactor(0)`，仅暗世界、HUD 保持明亮）；并从 `renderUI` 移除原自绘全屏 dim
- [x] **验收**：coretest 39/39；三套 tsc 通过；浏览器 WebGL 实测：启动无报错、原生渲染一致、相机跟随、运行时强制 q3 验证夜战压暗正确、motes/beams 发射器运行时 explode 无报错
- [x] 攻击拖尾（弹弓飞石）→ 原生粒子拖尾（`trail` 发射器，逐帧 `emitParticleAt(pr.x, pr.y)`；`CanvasGame.nativeProjectileTrail=true` 关闭自绘拖尾，仅浏览器/微信 Canvas 路径保留自绘）
